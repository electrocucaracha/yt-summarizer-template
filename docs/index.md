# YouTube Knowledge Template

Turn public YouTube playlists into notes you can review, search, and share.
This site documents the template and its tools; it does not host your notes.
Each generated repository stores its own notes and can publish its own knowledge portal.

## Documentation map

| Section | Use it to... |
| --- | --- |
| [How-to guides](how-to-guides/index.md) | Generate your first notes, publish a portal, search locally, or update your repository. |
| [Explanations](explanations/index.md) | Understand where summaries are generated and which files you own. |
| [References](references/index.md) | Look up integrations and manifest settings. |

New to the template? Start with [Create a knowledge repository](how-to-guides/create-knowledge-repository.md).
Changing the template itself? See the [contributor guide](https://github.com/electrocucaracha/yt-summarizer-template/blob/main/CONTRIBUTING.md).
