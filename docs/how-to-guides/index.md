# How-to guides

These tasks are for people creating or maintaining a generated knowledge repository.

| Guide | Use it to... |
| --- | --- |
| [Create a knowledge repository](create-knowledge-repository.md) | Configure a public playlist and generate your first notes. |
| [Publish a knowledge portal](publish-knowledge-portal.md) | Preview your notes locally and share a static portal on GitHub Pages. |
| [Search notes locally](search-notes.md) | Index your notes with QMD without publishing them. |
| [Update a generated repository](update-template.md) | Adopt shared tooling changes without replacing your notes or settings. |
